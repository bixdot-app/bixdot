BixDot Setup

BixDot needs a few things installed before it can run. This is a one-time setup.

🐍
Python 3.11+ Checking…
BixDot's backend is written in Python. You need version 3.11 or newer.
Download Python →
✓ Check "Add Python to PATH" during install. Then click Check Again below.
📦
Python packages Waiting…
BixDot needs some Python libraries (FastAPI, httpx, etc.)
Open a terminal and run:
pip install -r requirements.txt
The requirements.txt file is in the BixDot folder where you installed it.
🦙
Ollama (local AI) Waiting…
Ollama runs the AI model on your device. No cloud, no API key needed.
Download Ollama →
After installing, pull the AI model (run once, ~2GB download):
ollama pull llama3.2

BixDot runs 100% on your device. Nothing is sent to any server.
